# History

- `2026-10-31-brainstorm-lms-options.txt`: the owner's original brainstorm, uploaded at the start of the founding session on 31 October 2026. It compares Moodle, Open edX, Canvas, Frappe Learning, LearnHouse, Chamilo, BookStack and Google Classroom, and ends at the two conclusions that shaped this repository: the real need is small (subject, chapter, lesson, material, with controlled access), and zero recurring cost is a hard requirement. Kept verbatim as evidence; it is not a control document.
