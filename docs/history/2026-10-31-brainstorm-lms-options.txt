Canvas is excellent but not my preferred fork

Chamilo deserves more attention than its GitHub stars suggest
Chamilo LMS GitHub repository

Its repo has about 1,000 stars / 560 forks, but the project reports use by more than 40 million people since 2010. It was updated October 1, 2026.

HR, SIS, ERP, e-commerce and other systems.

Both are serious institutional systems.

I wouldn't use either as the foundation for a new modern product unless there were specific institutional requirements forcing the decision.

Yes — the license allows you to self-host Frappe Learning, including for your own school/business, and you are not required to use Frappe Cloud.

Frappe Learning itself is licensed under AGPL-3.0. That allows you to use it, modify it, run it on your own infrastructure, and even use it commercially. The important AGPL condition is that if you modify the software and make that modified version available to users over a network, those users must be able to obtain the corresponding source code of that modified version under the AGPL. 

So this is perfectly valid:

Our school

   ├── Our teachers

   └── Frappe Learning
           ↓
      self-hosted
You can also change branding and customize the application. The AGPL does not mean you have to publish your student data, passwords, uploaded PDFs, videos, database, or private educational content. The copyleft requirement concerns the software/source-code modifications, not the data stored in the LMS.
